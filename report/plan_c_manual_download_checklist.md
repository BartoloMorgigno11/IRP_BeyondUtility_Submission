# Plan C Manual Download Checklist

This checklist lists sources the user may manually acquire. Codex must not
download these artifacts automatically.

After placing any file locally, update
`data/artifact_manifests/plan_c_artifact_manifest.csv` and run:

```powershell
python src/audit/validate_plan_c_artifacts.py --manifest data/artifact_manifests/plan_c_artifact_manifest.csv
```

Use `--hash` only after expected SHA-256 hashes are recorded:

```powershell
python src/audit/validate_plan_c_artifacts.py --manifest data/artifact_manifests/plan_c_artifact_manifest.csv --hash
```
